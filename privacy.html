개인정보처리방침

시행일: 2026-10-19

  • junlab-agent는 소유자 한 사람만 사용하는 개인 도구이며, 다른 사용자의 데이터를 수집하지 않습니다.
  • Google 계정에서 요청하는 권한은 gmail.readonly(메일 읽기 전용) 하나이며, 메일을 보내거나 수정·삭제하지 않습니다.
  • 읽은 메일의 발신자, 제목, 본문 앞부분은 분류와 알림을 위해 소유자 본인의 기기에만 저장합니다.
  • 데이터는 판매하거나 제3자와 공유하지 않으며, 광고에 사용하지 않습니다.
  • Google API에서 받은 정보의 사용은 Google API Services User Data Policy의 제한적 사용(Limited Use) 요건을 따릅니다.
  • 소유자는 Google 계정 설정에서 언제든 접근 권한을 철회할 수 있습니다.

Privacy Policy

Effective: 2026-10-19

  • junlab-agent is a personal tool used only by its owner. It does not collect data from anyone else.
  • It requests a single Google scope, gmail.readonly. It never sends, modifies, or deletes mail.
  • Sender, subject, and a short text excerpt are stored only on the owner's own device, to classify messages and notify the owner.
  • No data is sold, shared with third parties, or used for advertising.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Access can be revoked at any time from the owner's Google Account settings.
